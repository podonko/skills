Для скачивания откройте файл и нажмите Download raw file. Если открылся проигрыватель, сохраните видео через меню браузера.

Субтитры: короткие русские фразы, белый текст с тёмной обводкой, ниже лица. Таймкоды отдельно рассчитаны для каждой версии. Исходный звук и длительности сохранены.

Текст распознан локально через sherpa-onnx / GigaAM v3 с дополнительной сверкой Zipformer. Это автоматическая расшифровка: отдельные ошибки распознавания возможны. Отдельные файлы `.srt` позволяют исправить текст и таймкоды.
